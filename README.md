## Project Overview 🗺️

Get Hub is a cross-platform app store for releases on GitHub, Codeberg and other Forgejo or Gitea forges, designed to simplify discovering and installing open-source software. Fork of GitHub store, that just like Updatium, encourages inclusion instead of discrimination of a whole nation.

> [!IMPORTANT]
> **macOS Users:** You may see a warning that Apple cannot verify Get Hub. This happens because the app is distributed outside the App Store and is not notarized yet. Allow it via System Settings → Privacy & Security → Open Anyway, or run `xattr -dr com.apple.quarantine /Applications/Get-Hub.app` after installing.

**Scoop**

```powershell
scoop bucket add Get-Hub https://github.com/omeritzics/Get-Hub-scoop-bucket
scoop install omeritzics/Get-Hub
```

**WinGet**

```powershell
winget install zed.rainxch.githubstore
```

> [!TIP]
> **macOS Users:** Install Get Hub with Homebrew.

**Homebrew**

```bash
brew tap omeritzics/Get-Hub
brew install --cask Get-Hub
```
